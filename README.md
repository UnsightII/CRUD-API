# Task API

A simple REST API for managing a to-do list.

This project was created as part of the FlyRank Backend Development Track – Week 2 assignment. The API allows users to create, read, update, and delete tasks using CRUD operations.

## Features

- Create a task
- Get all tasks
- Get a single task
- Update a task
- Delete a task
- Input validation
- Proper HTTP status codes
- Swagger API documentation
